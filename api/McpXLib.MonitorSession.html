Remarks

モニタ(コマンド: 0802)は登録済みのデバイスを読み出すだけの軽量なコマンドのため、 登録は1回だけ行い、本セッションで繰り返し読み出すのが効率的です。
PLCの再立上げなどで登録内容が消去された場合は、再度 MonitorRegist(Action<MonitorBuilder>) で登録し直してください。
