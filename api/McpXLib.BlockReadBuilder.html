Remarks

追加した範囲（ブロック）を、複数ブロック一括読出し（コマンド: 0406）でまとめて読み込みます。
読み取り完了後、各コールバックに変換済みの値が渡されます。

Methods

Add<T>(Prefix, string, ushort, Action<T[]>)

読み込むデバイス範囲と、読み取り後に値を受け取るコールバックを追加します。

public BlockReadBuilder Add<T>(Prefix prefix, string address, ushort length, Action<T[]> onRead) where T : unmanaged

Parameters

prefix Prefix

読み込み対象の先頭デバイスコードを指定します。

address string

読み込み対象の先頭アドレスを指定します。

length ushort

読み込み対象の要素数（T型の要素数）を指定します。

onRead Action<T[]>

読み取り完了後に、変換済みの値T[]を受け取るコールバックを指定します。

Returns

BlockReadBuilder

メソッドチェーン用に自身を返します。

Type Parameters

T

読み込むデータの型。bool（ビットデバイスのみ）、short、int、float などの値型を指定します。
ビットデバイスをワード型で指定した場合は、1ワード=16点として読み込みます。

Exceptions

ArgumentException

ワードデバイスに bool を指定した場合にスローします。

NotSupportedException
