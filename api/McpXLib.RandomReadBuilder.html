Remarks

Add<T>(Prefix, string, Action<T>) でデバイスと「読み取り後に呼ばれるコールバック」を並べます。 型に応じてビット／ワード／ダブルワードのアクセス単位が自動的に振り分けられ、読み取り完了後に各コールバックへ 変換済みの値が渡されます。
