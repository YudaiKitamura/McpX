# Security Policy

[日本語は下にあります](#セキュリティポリシー)

## Supported Versions

Security fixes are made for the latest release of McpX.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.
Report them privately from the [Security tab](https://github.com/YudaiKitamura/McpX/security/advisories/new) of this repository (GitHub private vulnerability reporting).
Include the affected version, the steps to reproduce, and the impact if possible.

---

# セキュリティポリシー

## サポート対象のバージョン

セキュリティの修正は、McpX の最新のリリースに対して行います。

## 脆弱性の報告

脆弱性は、公開の Issue では報告しないでください。
このリポジトリの [Security タブ](https://github.com/YudaiKitamura/McpX/security/advisories/new)（GitHub の非公開の脆弱性報告）から報告してください。
可能であれば、影響するバージョン、再現手順、影響の範囲を記載してください。
